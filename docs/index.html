📦 Installation & CDN

Include TaxUI in your web project with a single line of HTML via CDN, install it via NPM, or import standalone modular builds.

1. Quick CDN Inclusion (Recommended)
Instant Setup

Place this inside your document's <head> tag:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Elabsurdo984/taxui@1.0.0/dist/taxui.min.css">
2. Via NPM / Package Manager
npm install taxui

Import into your application stylesheet or bundler:

@import "taxui/dist/taxui.min.css";

⚡ HTML Starter Boilerplate

Copy and paste this production-ready boilerplate to start building immediately with Dark Mode and dynamic theme variables. 

<!DOCTYPE html>
<html lang="en" theme="dark" theme-accent="blue">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My TaxUI App</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Elabsurdo984/taxui@1.0.0/dist/taxui.min.css">
</head>
<body layout="sticky-footer">

  <header sticky="glass" style="padding: 1rem 2rem;">
    <div layout="split">
      <strong>TaxUI App</strong>
      <button variant="primary" size="sm">Action</button>
    </div>
  </header>

  <main style="padding: 2rem;">
    <div card="glass" interactive>
      <div card-body>
        <h3>Hello World</h3>
        <p>Built with zero JavaScript runtime overhead.</p>
      </div>
    </div>
  </main>

  <footer style="padding: 1.5rem 2rem; border-top: 1px solid var(--color-border); text-align: center;">
    <p style="color: var(--color-text-muted);">© 2026 TaxUI Framework</p>
  </footer>

</body>
</html>

📂 Accordions & Collapsibles

Pure HTML5 <details> accordions with custom animated rotating chevrons and native auto-exclusive closing via the name attribute.

Live Preview: Connected Accordion
What is TaxUI?
TaxUI is a lightweight declarative CSS framework designed for building fast, modern web applications with pure HTML attributes.
Does it require JavaScript?
No. All components (accordions, tooltips, dark mode, responsive grids) work with 100% pure CSS and native HTML5 elements. 
<div accordion>
  <details name="faq" open>
    <summary>Section Title</summary>
    <div accordion-body>Collapsible body content...</div>
  </details>
</div>

✂️ Truncation, Clamping & Aspect Ratios

Multi-line Text Clamping

TaxUI provides clean declarative attributes for multi-line clamping without requiring custom CSS classes or tricky line-height calculations. Any overflow text is gracefully truncated with an ellipsis.

clamp="2"
Single Line Truncate

This is a very long single-line text that automatically truncates when reaching container boundaries.

truncate 
<!-- Single-line Truncate -->

<!-- Multi-line Clamp (2 to 6 lines) -->
